# Static modifiers for Ark colonies (colony scope; added with add_modifier on the colony, as vanilla
# does for Arkship modifiers, e.g. events/nomads_arkship_events.txt:8390). planet_* keys apply to the
# colony and ship_* keys reach the carrier Ark (situation stage example: common/situations/14_nomads_situations.txt:1347-1354).
# 4.4.4 note: "Any scripted modifier needs to be updated to work on colonies rather than planets."
#
# Biomass (decision D4): biomass is the Wilderness pop count, reset monthly (events/origin_events_wilderness.txt:40-55),
# so there is no biomass output modifier. Biomass income is pop growth: the former biomass bonuses below are
# logistic_growth_mult, the vanilla pop growth key (also used in civic modifiers, common/governments/civics/02_gestalt_civics.txt:1231-1234,
# and static modifiers, common/static_modifiers/18_static_modifiers_first_contact_dlc.txt:417).
# Their values are design values, balance pending; they are not an equivalence to the old biomass numbers.
