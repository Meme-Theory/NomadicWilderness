# Costs: Ark districts and zones charge alloys (nomads pay through common/inline_scripts/buildings/nomadic_cost_switcher.txt).
#   Wilderness districts charge minerals + 50 biomass (common/districts/05_wilderness_districts.txt:1-3,48-59), and the
#   biomass only stays spent through the on_queued pop kill in common/inline_scripts/buildings/on_all_wilderness_buildings_districts.txt:13-43.
# Jobs: Wilderness has no own job keys. It works the gestalt jobs, which rename themselves for is_wilderness_empire
#   (common/pop_jobs/04_gestalt_jobs.txt: technician_drone -> photosymbiont :2354, agri_drone -> pollinosymbiont :2247,
#   mining_drone -> grubsymbiont :2090, warrior_drone -> tamersymbiont :2612, coordinator -> choirsymbiont :488).
#   "Nectar Gatherer" and "Mycelial Comptroller" do not exist in vanilla.
#
# Each Uprooted deck is a copy of the vanilla deck with:
#   potential -> add  owner = { nw_is_uprooted_empire = yes }  and the vanilla deck gets the inverse
#   resources -> cost = { biomass = 50 } plus the vanilla on_queued/on_unqueued biomass handling
#                (decision D4: one-off costs are biomass, paid by killing that many Wilderness pops)
#   The capital Ark's starting decks are built by the start event (decision D14, plan-missing-scripts.md P4).
#   jobs      -> unchanged vanilla gestalt jobs (they display as Wilderness jobs once is_wilderness_empire matches)
