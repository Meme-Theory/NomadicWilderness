Mesh files (`*.mesh`), animations (`*.anim`) and textures (`*.dds`) go here. The brief, the entity names and the order of work are in `docs/03-arkship-models.md` (§1, §7). Required: the Seed and nine Ark hulls, plus nine frames if the frame entity turns out to be culture-prefixed. Rootholds, Seedwings, modules and spinal mounts are optional. The two `.asset` files here predate decision D2-B and are rebuilt in plan P12; the mesh definitions move to a `.gfx` file under `objectTypes`.
